# 小红书上传与推广调研

核验日期：2026-10-12。对象为 Builder Hub「小工具」，不是小程序开放平台。以下区分官方规则、媒体观察和创作建议；不将搜索摘要当作当前活动报名凭证。

## 1. 上传与运行边界

一手来源：[小红书小工具容器能力清单](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)，页面更新 2026-09-22；[官方小工具内测介绍](https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8322bpulog7u06f48k3g2740000000016rhrpc6)，页面未标发布日期。

现行要点：全本地 H5、单一 index.html 入口、外置脚本、无外链和联网；ES2017 / Chrome 61 基线，Android 8.1，iOS 18.4 起。官方明确要求先取得上传页当前完整改写口令、加载其指定 Skill，再校验打包，公开能力清单不能替代此步骤。

Storage 需客户端 9.46.0+；低版本可容错降级，不能保证永久存档。9.49+ 提供评论草稿 API。剪贴板（含 execCommand copy/cut/paste）、站外跳转禁用；未列出关注作者 API。

操作路径：创作者服务中心 → Builder Hub → 小工具 → 创建 / 上传 / 审核；审核通过后在移动端笔记组件中挂载。上传页当前大小限制、图标规格、账号资格仍须现场核对，不能把社区模板中的「5 MB / 单文件 2 MB」当成当前官方定案。

## 2. 鸿蒙、安卓、苹果要分别验收

公开官方清单只声明 iOS / Android 双端，未明确保证原生 HarmonyOS 小红书开放小工具入口。华为手机不能笼统当作安卓：应记录系统版本、是否原生鸿蒙、小红书版本及实际入口。

| 范围 | 应验证的实际环境 | 核心验收 |
|---|---|---|
| Android | 低端 / 老 WebView 与主流安卓各一台，小红书容器和普通浏览器分别测 | 触控双指、长按无选中、可见按钮、音频开关、存档重进、分享失败提示 |
| iPhone | 官方最低支持系统附近及较新系统，Safari 和小红书各测 | 安全区、地址栏高度变化、底部手势、来电 / 后台暂停、手势后音频恢复 |
| 华为 HarmonyOS | 一台原生鸿蒙真机；如需覆盖旧华为系统则另列 | 先确认小红书小工具入口，再验证 Canvas、Touch / Pointer、音频、SDK 和本地缓存 |

浏览器模拟尺寸只证明布局与部分交互，不等于真机系统或小红书容器验证。原生鸿蒙如没有平台入口，游戏代码无法替平台开放入口；可提供普通浏览器试玩，但仍需真机核验。

## 5. 本作品的图文方向

优先标题：「小时候炸潜艇的快乐，我做回来了」；备选：「一颗水雷连炸几艘？来试试深海较量」。正文先讲玩家怎么赢与连爆感受，再讲后五波敌人和限时道具，最后交代存档、历史成绩、勋章和作者反馈。

配图建议使用本作实际渲染截图：①封面含舰船 / 潜艇 / 清晰游戏名；②连环爆炸；③后五波与限时加成；④历史成绩曲线；⑤勋章 / 分享卡。测试预置场景应标「演示画面」，不伪装真实玩家成绩。正文入口应在审核挂载后写「点笔记里的小工具开玩」，不能把局域网地址当公开入口。

长文适合保存为项目介绍及图文分镜；实际发布另备精简正文，避免超过发布器限制。分享端 API 明确标题最长 20 字、正文最长 1000 字；真实发布页面以其校验为准。按实际实现描述免费 / 无广告，绝不写「全手机完美适配」「永久云存档」或未经验证的宣传。

推广验证建议：先发一篇真实体验帖，观察评论里是否看懂玩法、能否打开和是否反馈手机型号；后续再以新关卡 / 道具 / 实测修复做更新笔记。标题与封面各次只改一项，记录平台可见曝光、点击、点赞、收藏和关注变化。离线游戏没有后台游玩分析能力，不虚构留存率、转化率或自动收集玩家数据。
