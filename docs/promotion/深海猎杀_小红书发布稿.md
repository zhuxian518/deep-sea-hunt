# 正文（直接复制这一部分）

左右开船，往海里投下一颗水雷。
先炸掉一艘，再把旁边几艘一起带走——我想把这种简单的快乐做回来，就有了《深海猎杀》。

它不是只要一直投弹就行：水雷要慢慢沉，潜艇也一直在动。看准它们凑近的时机，一颗雷炸出一串，才是最爽的那一下。

这次做了十波关卡：
🌊 前五波熟悉手感，后五波逐渐增加追踪鱼雷、多枚齐射等攻击。
💥 不同潜艇分数不同，越深越值；每波还会根据“用了多少雷、炸了多少艇”结算效率奖励。
🛟 第六波起有机会掉落限时补给：水雷加速、强化水雷、舰船护盾，开船接住才能获得。
💾 自动存档＋手动保存，下次在同一设备、同一存储环境可以接着玩。
🏅 历史成绩曲线、十枚勋章、结算成绩卡，让每次进步都能留下来。
🎵 背景音乐重新做了，也能单独关掉；手机吃力可以试试低特效。

点这篇笔记挂载的《深海猎杀》小工具就能开玩。
给你一个小挑战：一颗水雷，最多能连炸几艘？

玩完来评论里告诉我，你打到第几波。Bug 或建议也欢迎留言、私信，附上手机型号、系统版本和具体问题，方便我继续改进。
