# 正文（直接复制这一部分）

有没有人还记得电脑上那个炸潜艇？
一艘船在上面左右跑，水雷慢慢往下沉，潜艇从下面穿过去。

我照着这个玩法，自己做了一款《深海较量》，手机也能玩。

最想让人体验的，是这几秒：
两艘潜艇快靠到一起了，先别急，再等一下……投！
第一艘炸了，旁边那艘也跟着炸，分数连着往上跳。

但扔早了也很气。三颗水雷还在往下沉，下面偏偏来了个好机会，只能看着它过去😂
水里同时只能有三颗雷。得留一颗，也得算一下它沉下去时，潜艇会开到哪儿。

一共十波。后面潜艇会用追踪鱼雷、多枚齐射还击，开船接到的护盾也只挡一次。想等一波连炸，还得先躲开冲上来的鱼雷。

中途有事可以存档，下次在同一设备接着打。游戏里没有插播广告，也不用另外下载一个 App。

入口就是这篇笔记挂载的《深海较量》。
