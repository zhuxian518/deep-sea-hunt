# 电脑上那个炸潜艇，我做了手机版

有没有人还记得这个画面？

一艘船在水面上左右跑，潜艇从下面穿过去。你投下一颗水雷，它慢慢沉下去。明明刚才还对得很准，等雷到了，潜艇早开走了。

我照着这种玩法，自己做了一款《深海较量》。这次用手机也能玩，左右开船，往下投雷。

![深海较量连爆画面](../previews/promo-03-chain.png)

*演示画面：由本作实际渲染器展示的连爆场景，分数为示例。*

## 两艘快碰头了，现在扔不扔？

这就是我想保留下来的乐趣。

你看到两艘潜艇越靠越近，想再等等，凑到一起炸。可水雷沉下去需要时间，等它们真的挨到一起才扔，可能已经来不及。

提前一点，投下去。第一艘炸了，旁边那艘也跟着炸，分数连着往上跳。

差一点没碰到，也很容易让人惦记：刚才往左挪一点，是不是就中了？

这次把水雷下沉时的晃动、潜艇划过海水的尾迹、鱼雷后面的气泡都补上了。爆炸的时候，能看见火光和冲击波在水下散开。

## 水里最多三颗雷，别一下全扔完

三颗雷都还在下沉，下面却刚好来了个连炸机会——这时候就只能看着。

所以最好留一颗。雷不是整局只有三颗，而是水里同时最多三颗；命中或落到底部腾出位置后，就能继续投。

往深处打还要多算一点提前量。越深的目标，命中后分数越高。每波打完也会看你用了多少雷、击沉多少潜艇，少扔几颗、多炸几艘，会拿到额外奖励。

![深海较量后期战斗](../previews/promo-02-combat.png)

*演示画面：后期敌人和限时能力组合展示；补给需在游玩中获得。*

## 别光顾着看水下，鱼雷上来了

目前做了十波。前五波先熟悉下沉时间，后五波会出现追着舰船转向的鱼雷，还有一次打出多枚鱼雷的潜艇。

想等几艘靠近了再炸，可鱼雷已经冲上来了。继续等，还是先开船躲？连炸机会和保住舰船，经常得一起考虑。

第六波起有机会获得水雷加速、强化水雷和护盾。它们都是短时间的帮手：护盾只挡一次，补给也得自己开船去接，不是捡到之后就能一直横着走。

## 有事先走，回来接着打

玩到后面突然要回消息、接电话，总不能回来又从第一波开始。

游戏加了自动存档，暂停时也能主动保存。同一设备、同一存储环境再打开，点“继续上次”就行。回来先停在暂停页，准备好了再继续。

![深海较量首页](../previews/promo-01-home.png)

*实际首页；有存档时会显示“继续上次”。存档在本机，不跨设备同步。*

## 打完有张成绩单

这一局打了多少分、连炸得怎么样，都能留在成绩卡里。想和别人比比，就把卡片晒出来。

![深海较量成绩卡](../previews/promo-06-card.png)

*演示画面：展示用示例成绩；分享、保存由玩家主动操作，需客户端支持。*

也可以翻翻自己的历史曲线，看看分数有没有往上走。游戏里还有十枚勋章，第一次连爆、闯过后面的波次，都可以慢慢解锁。

![深海较量历史成绩](../previews/promo-04-history.png)

*演示画面：曲线使用示例数据，实际记录来自本机已完成对局。*

![深海较量勋章](../previews/promo-05-medals.png)

*演示画面：部分勋章解锁的示例状态。*

音乐和音效可以分别开关，也可以安静玩。游戏里没有插播广告，不用另外下载 App。

入口在这篇笔记挂载的《深海较量》。先来一局，看看一颗水雷能连炸几艘，评论区晒张成绩卡。

我会继续改这个小游戏。哪一波打起来最有意思，哪里还不顺手，也欢迎留言或私信告诉我。
