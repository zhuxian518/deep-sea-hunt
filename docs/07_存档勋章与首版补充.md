# 存档、成绩、勋章与正式首版补充

状态：2026-10-12，v1.0.0 首版候选；同06号扩展共同覆盖初始PRD/TDD中的五波规划。本文件描述实际行为，手机实机与小红书审核状态见09/交付说明。

## 对局存档

正式局开局建立存档；每15秒有效战斗时间、完成一波、暂停/进入后台时自动保存；暂停页可手动保存并等候成功提示。页面关闭事件只作补救，操作系统强杀可能丢失最后一次自动保存之后的变化，不承诺关闭瞬间必定落盘。存档包含随机数状态、实体、连爆关联、分数、生命、波次、已结算奖励与限时能力，继续时先暂停等待用户准备。

一个正式存档，重新开始会替换。完成对局后原子更新成绩/勋章并清除对应存档。版本不兼容或无效的战斗存档仅清理存档字段，保留有效历史和最高分。旧资料自动补齐新字段。Storage适配层沿用官方9.46+原生JSON字符串接口，低版本/普通浏览器使用localStorage；读写失败不冒充成功，不覆盖未知原生记录。这里不是跨设备云存档。

`?practice=6` 从第六波起练习；不覆盖正式存档、最高分、累计局数、正式勋章。练习结束的历史行和曲线节点单独标识。

## 历史成绩与十枚勋章

历史保留最近60个已完成对局，包括失败/通关/练习，记录分数、击沉数、投弹数、最大连爆、到达波次与时间。正式累计完成局数/通关数/击沉数独立维护，不随历史截断清零；中途保存退出尚未完成的局不计入历史。

曲线纵轴按本机当前历史最高分缩放，不是不同用户的排名或线上排行榜。空列表、单局、零分都有有效显示。

勋章：初次出航（1局）、又来一局（3局）、海上常客（10局）、一雷三响（3连爆）、连爆好手（5连爆）、连锁大师（8连爆）、小试锋芒（3000分）、深海王牌（10000分）、驶入深海（正式进入第6波）、深海猎手（正式通关10波）。结束时按正式纪录解锁，重复结算同一对局不重复计数。

## 作者与反馈

作者主页由用户提供： https://xhslink.cn/o/8ikp6N0Ci0N 。该地址仅保留在源码配置、文档和开发预览，正式包不包含这个外部URL。小红书容器内不触发外链、不使用剪贴板/execCommand；引导回当前笔记点头像关注/私信，也可在笔记留言。

客户端9.49+且方法存在时，用户点击并填写草稿后，先保存资料，再调用 `miniTool.interactionOpenApi({payload:{action:'post_comment',content},saveToAlbum:false})`。只打开评论草稿，需要用户自己检查发布；方法失败/版本不支持时说明手动留言路径。不传猜测的noteId，不自动发消息、不自动关注。

结算成绩卡仍沿用官方分享/相册接口，主动点击才调用；失败不提示已分享。现有卡片不是线上排行榜。

## 新背景音乐

原创D小调、100 BPM、32小节/76.8秒循环，含引子、主题、变化、收束；低音、和声、旋律、回应、铃音和三类节奏声部。后五波增加节奏密度，倒计时/过波留出空间；爆炸和受击短暂降低音乐音量。音乐与音效分别开关，暂停/后台停止、手势后恢复；WebAudio不可用时保留静音玩法，最多32个在途音乐声部，不使用外部音频。
