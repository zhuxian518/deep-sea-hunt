## 实施顺序与完成判据

1. 文档：修正引用名、补证据矩阵、官方平台契约、素材登记、原作测量表。
2. 核心：固定60Hz模拟、seed PRNG、扫掠碰撞、延时扩张的伤害场、去重和计分；自动测试边界、时序、确定性。
3. 界面：原创海蓝街机外观、首页/教程/倒数/暂停/波间/结算；键盘和双指控制、退后台暂停。
4. 五波：8/12/15/15/20敌人；第三波编队；S03从第四波出现。保留离场结束规则，不要求零漏艇才通关。
5. 平台：原生/浏览器/内存存储、成绩卡预览、用户点击才分享/保存、原创合成声音、低特效档。
6. 交付：测试、浏览器三尺寸检查、离线资源审计、游戏预览ZIP和文档ZIP、README与测试报告。

## 冻结的工程决策

- 不引入社区脚手架运行时。使用 ES modules 开发，esbuild 输出 Chrome 61 / ES2017 的单个 IIFE 外置经典脚本；JSON配置在构建时内嵌，不运行时请求。
- 世界1000×1200、海面155；同屏5弹、冷却0.18s、沉速300；3生命、无敌1.5s；三类敌人分值100/150/180、速度140/235/120；爆炸半径95、增长650、伤害窗口0.3s，均为原创初值。
- 世界等比完整可见；宽屏中心战斗台，手机专注战斗和底部三个独立按钮，低屏高采用紧凑排版；不裁切敌人区。
- 爆炸来源按 tick 开始时快照处理，新产生伤害场下一tick扩张；直接命中与扩散命中一起按时间/优先级/sourceId/targetId排序。死艇立即退出逻辑，视觉独立保留。
- 鱼雷命中扫掠线段 vs 扩张舰体AABB。新发射鱼雷下一tick才运动；清波需等待危险鱼雷及爆炸结束。
- 敌人离场视为本波目标已解决，记录漏艇不罚生命。五波全部完成进入胜利结算，不自动开20波。
- 分数公式 `floor(base * min(1 + 0.5*depth, 3))`；chain统计击杀数与分数，无限制历史日志；完成链记录后清除。
- 原生存储以官方2026-09-22网页为准：JSON字符串、读取异常保留内存且阻止覆盖未知旧数据；成功确认不存在才迁移；写入串行。迁移失败允许下次打开重试。
- 成绩分享属于V1.1增强，本次实现但不作为已真机通过的承诺；不做排行榜、Boss、外部服务和拖动模式。
- 固定 DPR 上限2，可选低特效；不自动改变逻辑速度。旧Chrome不支持的CSS仅增强，flex基础布局、100vh与JS实际视口高度保底。
