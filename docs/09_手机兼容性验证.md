# 手机兼容性与验证边界

更新：2026-10-12。本游戏是 Canvas H5，需要在手机浏览器或小红书小工具的网页容器中运行。适配采用能力检测，不按手机品牌或 User-Agent 分支；本文不代表鸿蒙原生应用支持或三个系统均已通过实机验收。

## 本轮已完成的适配

- 长按移动：左右箭头由 CSS 线条绘制，元素内没有可选中的箭头字符；操作区及子元素禁止选择、拖拽和系统长按菜单。只限制游戏操作区，反馈链接等页面内容仍可正常选择。
- 多指：每个指针/手指独立记录，允许一指移动、一指投弹；松开其中一指不会释放另一指。手指移出按钮停止对应动作，滑入另一个按钮切换动作。
- 输入降级：优先 PointerEvent；缺失时采用 TouchEvent，并保留鼠标操作。指针捕获不存在或抛错时仍能通过窗口级释放事件结束按压。非被动 touch 监听显式阻止操作区默认手势。
- 后台释放：失去焦点、页面隐藏、pagehide、暂停/禁用操作时清空所有按键和触点，避免回到游戏后持续移动或自动投弹。游戏控制器另行管理自动暂停与存档。
- 屏幕布局：320px 窄屏保留可点按的按钮；竖屏使用实际视口高度；横屏手机将操作区排在海域右侧，避免原先固定 680px 高度或切回桌面布局使按钮落到屏幕外。横屏海域完整缩放，未裁去水底目标。
- 刘海/圆角/手势条：viewport-fit=cover，页面顶部、左右、底部按 safe-area-inset 留白；不支持 env/max 的旧引擎使用同一规则中先声明的基础留白；横屏 padding 也明确提供 `0 8px 8px` 后备值。`inset` 提供四边定位后备值，横屏按钮和音频开关间距采用 margin，兼顾缺少 flex gap 的旧引擎。
- 图像与性能：Canvas 按比例显示完整世界，渲染像素比最多 2；低特效模式减少气泡/碎片并关闭震动。没有依赖远程图片、字体或音频。
- 音频降级：现有 AudioMixer 检测 AudioContext / webkitAudioContext，用户点击后恢复音频；不可用或初始化失败时静默继续游戏。音乐默认关闭；后台暂停音频。静音开关不能绕过系统静音、容器音频权限或系统中断。

小红书 SDK 的存储、分享、保存图片与宿主容器版本有关，独立浏览器主要验证 H5 游戏本体。浏览器本地记录按当前浏览器/容器存储隔离，不能据此承诺跨设备或跨容器同步。

## 可重复的实机体验路径

1. 正式入口从第一波开始，后五波练习入口使用 `?practice=6`。竖屏和横屏分别操作，检查按钮始终可见、顶部和底部没有被系统区域遮挡。
2. 长按左/右至少 3 秒，同时用另一指长按投弹；先抬任意一指，再抬另一指；移出按钮再滑回。应无文本选中、无长按弹窗、无卡住动作。
3. 游戏中切到后台、锁屏再返回，检查先暂停、按钮均松开；继续后无异常追帧，存档能从主页恢复。
4. 开关音乐和音效；切后台、遇到电话/其他音频中断再恢复。音频失败时游戏仍应可操作，不能强制自动播放。
5. 第六至十波观察追踪/齐射鱼雷、爆炸、护盾/强化雷/加速等场景，连续运行至少 10 分钟；必要时开启低特效，比较发热、卡顿和触控响应。
6. 在实际小红书上传后的容器验证分享成绩卡、保存图片、手动/自动存档、历史曲线、勋章与作者反馈入口。模拟浏览器通过后仍需记录手机型号、系统版本、小红书版本与通过/失败现象。

实机验证记录应补在本文件，不能把尚未测过的设备写成“全机型兼容”。
