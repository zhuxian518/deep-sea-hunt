## 3. 平台公开契约核查结果

P01 明确：完全离线、Canvas 2D 可用、Chrome 61 / ES2017 基线；外置包内经典脚本，禁止内联脚本、行内事件、外部资源、网络请求、动态执行、WASM、Worker、iframe、站外跳转、文件下载。CSS 需保留旧内核可用的布局与高度降级。

官方 Storage 要求客户端 9.46.0+，`Math.floor(buildVersion / 1000) >= 9460`；同步启动参数缺失时可异步 `getLaunchOptions()`。`setStorage({key, data})` 的 **data 必须是 JSON 字符串**；`getStorage()` 返回 `{data}`，读取后解析。社区 P03 的 `data:any` 不能继续照搬。

版本未知 / 低版本可使用浏览器存储降级，所有获取、读写、解析须捕获异常。新版已选原生后失败不得静默改用另一份副本。仅成功读取原生并确认 `data === null` 时允许迁移旧浏览器副本；异常不是“没有数据”。

`postNote` 使用 `mediaInfo.image_resources:[{url:dataURI}]`，不传未核实字段。成功不代表审核通过；取消 / 失败保留成绩。`saveImageToPhotosAlbum({filePath:dataURI})` 可接收 PNG data URI，必须由用户点击触发。首版只实现成绩预览和能力检测后的主动分享 / 保存，不自动发布。

P01 规定正式上传前须取得**上传页当时的完整改写口令**，加载对应版本 Skill 后校验打包。当前没有这份口令，工程自行出具的是本地预览包，不能标记官方发布候选。包体 <2MiB 是内部目标；社区 10MB 是参考，实际上传限制待后台确认。
