# 深海较量 1.0.0

正式版本日期：2026-10-12。源码标签：`v1.0.0`。

## 状态与来源

项目所有者在本次会话明确告知“官方审核已通过”，并要求将当前版本定为1.0.0。以这一确认记录审核状态；本轮没有代为登录、上传或重新审核，也没有取得审核单号或公开挂载笔记链接。

本版本以当前工作区已审核游戏为基线。本轮补齐仓库维护资料、统一正式包命名、强化归档校验，没有修改 `src/`、`index.html` 或 `public/` 的游戏内容。最后一次玩法变更为 `5a5f04f`（混合艇型速度差与后期连爆范围）；版本整理前源码头为 `e8c89eb`。

GitHub正式Release是开发归档，公开笔记发布状态尚未登记；两者不能混为一谈。推广文案按用户要求暂缓，包中保留草稿。

## 正式内容

十波、五类潜艇、直线/追踪/齐射鱼雷；水中同时三颗水雷；不同潜艇与深度计分、连爆及完成波次后的效率奖励；第六波起限时补给和更高攻击压力；水下晃动、尾迹、气泡、爆炸、受击特效；原创音乐和音效；手动/自动存档、60局历史曲线、十枚勋章、成绩卡、主动分享及反馈；后五波与最后三波练习隔离。

详细玩法变更见 [CHANGELOG](../../CHANGELOG.md)，维护入口见 [README](../../README.md)。当前不是原作全部关卡的复制，没有己方轰炸机支援功能，也没有云同步或联网排行榜。

## 权限与存档

正常游戏不请求相机、麦克风或相册读取。保存成绩卡可能需要相册写入；存档使用内部存储，不请求文件管理权限。记录只在当前设备与小工具存储环境内，清理数据或换设备不会同步恢复。
