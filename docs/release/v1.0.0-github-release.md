### 游戏内容

- 十波关卡、五类潜艇、直线/追踪/齐射鱼雷；同时三颗水雷，后期连爆范围逐渐收紧。
- 类型与深度计分、连爆和投弹效率奖励；第六波起限时加速、强化与单次护盾。
- 水下尾迹、气泡、晃动、爆炸和受击效果；原创音乐及音效。
- 自动/手动存档、历史曲线、十枚勋章、成绩卡、主动分享反馈与独立练习局。
