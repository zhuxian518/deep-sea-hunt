## 上传时使用哪个文件

只上传「深海猎杀-v1.0.0-上传候选.zip」。不要把文档ZIP或推广素材ZIP当游戏包上传；推广介绍HTML含说明、外部参考链接和大图，不属于小工具执行代码。

当前上传包4文件：index.html、app.js、style.css、icon.svg。图标SVG内的xmlns是标准命名空间，不是远程图片或联网请求。
