# 名称与界面文案

2026-10-12 用户确定游戏名为 **深海较量**。统一用于网页标题、首页、成绩卡、项目文档和交付说明。内部工程代号 `DepthChain` / `depthchain` 不影响用户界面或存储兼容性，继续保留。

首页玩法说明：**瞄准潜艇，投弹连爆。** 避免只看标题时无法理解游戏内容。

文案风格：像小游戏在跟玩家说话，简短、具体、容易懂；不堆军事术语或系统状态。错误提示说清发生了什么、接下来可以做什么，不把 SDK、后端或模拟时钟暴露给玩家。
